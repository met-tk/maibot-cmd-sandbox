# 沙盒终端与全能系统控制插件 (maibot-cmd-sandbox)

> 为 MaiBot（麦麦）打造的 Windows 原生沙盒终端执行、多显示器自适应截图、系统资源监控与桌面全能控制插件。支持管理员通过私聊或授权群聊，以**前缀指令**或**自然语言（LLM Tool Calling）**安全操控宿主机。

---

## 核心特性

1. **多显示器自适应截图**
   - 自动识别并优先截取主显示器（含高分屏/4K 适配）。
   - 支持全屏幕拼接全景截图（`all`）以及指定显示器序号（`1`、`2`、`3` 等）。
   - 截图自动编码并直接发送至当前私聊或授权群聊会话。

2. **沙盒文件管控与双重确认门禁**
   - **沙盒工作区内自由创作**：Agent 可在配置的沙盒工作区（默认 `D:\Agentworkspace`）内自由读取、创建、写入和追加文件，编写 Python 脚本与自动化工具套件。
   - **沙盒外部路径双重确认**：当开启 `sandbox_only_write = true` 且 `allow_write_outside_with_confirm = true` 时，任何向沙盒外部路径（如桌面、C 盘等）写入或追加文件的请求都会被暂存拦截，并向管理员发送告警提示；只有管理员在 60 秒内发送 `/确认写入`（或 `/confirm_write`）后方可执行。
   - 支持常用路径别名：`Workspace`（沙盒工作区）、`Desktop`（桌面）、`Downloads`（下载）。

3. **系统硬件与资源状态直查**
   - 免重型外部依赖，秒级读取物理内存总量与使用率、所有本地磁盘驱动器（C 盘、D 盘等）总容量与剩余空间、系统开机运行时长及沙盒工作区路径。

4. **进程管理与应用/网页启动**
   - 支持按关键字检索活跃进程（展示进程名与 PID），或按进程名 / PID 强制结束卡死无响应的程序。
   - 支持直接打开网址（`https://...`）、本地文件路径，或通过简称启动常用应用（如 `wechat`、`vscode`、`notepad`、`calc`、`taskmgr` 等）。

5. **原生 PowerShell 终端命令执行**
   - 原生 PowerShell 解释器驱动，默认在沙盒工作区内运行，支持自定义工作目录、批处理与 Python 脚本执行。
   - 内置超时截断与进程树级联清理（`taskkill /T /F`），防止子进程挂起或僵尸进程残留，并自动截断超长输出以防刷屏。

6. **严格权限校验与群聊白名单控制**
   - **管理员专属权限**：所有前缀指令与自然语言工具调用均强制校验 `admin_users`，非管理员触发将被拦截。
   - **群聊分级控制**：支持群聊总开关（`allow_in_groups`）与群聊白名单（`allowed_groups`），未授权群聊严格拦截所有系统控制指令与大模型工具调用，防止提示词注入与越权操作；管理员可通过指令动态管理群白名单。

## 环境要求与安装

### 1. 环境要求
- **操作系统**：Windows
- **宿主框架**：MaiBot（`host_application` 1.0.0 ~ 1.99.99，`maibot_sdk` 1.0.0 ~ 2.99.99）
- **Python 依赖**：
  - `pillow>=9.0.0`
  - `mss>=9.0.0`

### 2. 安装步骤
1. 将本仓库克隆或下载至 MaiBot 的 `plugins` 目录：
   ```bash
   git clone https://github.com/met-tk/maibot-cmd-sandbox.git
   ```
2. 在 MaiBot 所使用的 Python 环境中安装依赖（如尚未安装）：
   ```bash
   pip install "pillow>=9.0.0" "mss>=9.0.0"
   ```
3. 复制示例配置文件并按需修改：
   ```bash
   copy config.example.toml config.toml
   ```
4. 在 `config.toml` 的 `[security]` 节点中填入你的管理员账号（如 `admin_users = ["123456789"]`），保存后重启或重载 MaiBot 插件即可生效。

## 配置说明 (`config.toml`)

### `[plugin]`
| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enabled` | `bool` | `true` | 是否启用本插件 |
| `config_version` | `str` | `"1.4.0"` | 配置文件版本号 |

### `[security]`
| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `admin_users` | `list[str]` | `[]` | 管理员账号列表，支持纯数字账号或带平台前缀（如 `"qq:123456789"`） |
| `unauthorized_message` | `str` | `"权限不足：该系统控制与截图命令仅允许管理员执行。"` | 非管理员触发命令时的拦截回复（留空则静默忽略） |
| `enable_llm_tools` | `bool` | `true` | 是否允许大模型通过自然语言调用系统控制与终端工具 |
| `allow_in_groups` | `bool` | `false` | 是否允许在白名单群聊中执行系统控制与终端命令（总开关） |
| `allowed_groups` | `list[str]` | `[]` | 允许执行命令的群聊白名单（支持纯群号或 `"qq:12345678"`） |
| `unauthorized_group_message` | `str` | `"未授权群聊：..."` | 未授权群聊触发命令时的拦截回复（留空则静默忽略） |

### `[sandbox]`
| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `workspace_dir` | `str` | `"D:\\Agentworkspace"` | 默认沙盒工作区目录，命令执行与脚本编写的默认位置 |
| `sandbox_only_write` | `bool` | `true` | 是否默认仅允许在沙盒工作区内进行文件写入 |
| `allow_write_outside_with_confirm` | `bool` | `true` | 沙盒外写入是否开启管理员双重确认门禁（60 秒有效） |
| `timeout_seconds` | `int` | `30` | 单次终端命令执行的超时时间（秒） |
| `max_output_chars` | `int` | `2000` | 命令返回结果的最大字符数，超出部分自动截断 |
| `allow_system_control` | `bool` | `true` | 是否允许执行系统电源控制（关机 / 重启） |
| `shutdown_delay_seconds` | `int` | `60` | 关机或重启的默认倒计时缓冲秒数 |

## 使用指南

### 1. 直达前缀指令（仅限管理员）

| 指令 | 别名 | 说明 | 示例 |
| --- | --- | --- | --- |
| `/screen [目标]` | `/截图` | 截取电脑屏幕并发送到当前会话（支持 `primary`、`all` 或屏幕序号 `1`/`2`/`3`） | `/截图`、`/截图 all`、`/截图 2` |
| `/confirm_write` | `/确认写入` | 授权执行待确认的沙盒外部文件写入请求（60 秒内有效） | `/确认写入` |
| `/cmd <命令>` | `/terminal` | 在终端中执行 PowerShell / CMD 命令 | `/cmd dir`、`/cmd ipconfig` |
| `/关机 [秒数]` | - | 设置定时关机（默认按配置的 `shutdown_delay_seconds` 延时） | `/关机`、`/关机 120` |
| `/重启 [秒数]` | - | 设置定时重启 | `/重启 30` |
| `/取消关机` | - | 取消已计划的关机或重启倒计时 | `/取消关机` |
| `/cmd_group <子命令>` | `/群聊控制`、`/允许群聊`、`/禁用群聊` | 动态管理群聊总开关与白名单（支持 `on`、`off`、`add [群号]`、`del [群号]`、`list`） | `/cmd_group list`、`/cmd_group add` |

### 2. 自然语言交互（私聊或已授权群聊）

开启 `enable_llm_tools = true` 后，插件会向大模型注册以下 7 个系统工具，管理员可直接用自然语言指挥麦麦操作电脑：

- **屏幕截图**（`screenshot`）：支持 `primary` / `all` / 指定显示器序号。
  - 示例：“麦麦，帮我截一下当前电脑主屏幕”、“截一张所有屏幕合在一起的全景图”
- **硬件与资源查询**（`system_status`）：查询物理内存、磁盘剩余空间、开机时间与沙盒路径。
  - 示例：“帮我查一下电脑现在内存还剩多少，各个磁盘空间够不够”
- **沙盒文件管理**（`file`）：支持 `read`、`write`、`append`、`list`、`info`，支持 `Workspace/`、`Desktop/`、`Downloads/` 别名。
  - 示例：“帮我在沙盒里写一个测速脚本并运行一下”、“看看桌面有哪些文件”
- **应用与网页启动**（`open`）：打开本地程序、文件或网址链接。
  - 示例：“帮我打开记事本”、“在电脑上打开 https://github.com”
- **进程管理**（`process`）：支持按关键字列出进程（`list`）或按进程名 / PID 结束进程（`kill`）。
  - 示例：“查一下当前系统里运行了哪些 python 进程”、“帮我把卡死的 notepad.exe 关掉”
- **终端执行**（`terminal`）：在默认沙盒目录或指定工作目录执行原生 PowerShell / CMD 命令。
  - 示例：“帮我执行终端命令 git status 看看”
- **电源控制**（`power`）：支持关机、重启与取消关机倒计时。
  - 示例：“60 秒后帮我把电脑关机”、“取消刚才的关机计划”

## 安全机制说明

1. **身份与会话双重鉴权**：无论是前缀指令还是大模型工具调用，插件均会从事件上下文及近期消息记录中核验真实触发者身份；非 `admin_users` 成员或未开启 `allow_in_groups` / 未在 `allowed_groups` 中的群聊一律拒绝执行。
2. **沙盒隔离与二次确认**：默认将工作与写入范围约束在 `workspace_dir` 内；当需要向沙盒外写入时，强制要求管理员在 60 秒内发送 `/确认写入` 才会真正落盘。
3. **资源与进程保护**：所有终端子进程均绑定超时限制，超时后自动清理整个进程树；关机与重启默认带有缓冲倒计时，可通过 `/取消关机` 随时撤回。
